## 1. Overview

Script binding provides you with the highest level of data binding and control flexibility. By writing code in the integrated script editor, you can create complex logical rules, perform dynamic calculations, and process multi-source data fusion, thereby achieving advanced value binding functions that transcend standard attribute binding.

## 2. Working Principle

1. **Trigger and Execution**: Scripts can be set to execute when specific events are triggered (such as variable value changes, screen loading, timer expiration, etc.).
2. **Logic Processing**: In the script, you can access variables, control properties, and other objects in the system, and execute the logic you define.
3. **Output Binding**: Assign the script's final calculation result to one or more target properties of controls to complete value binding and updating.

## 3. Usage Method

1. Select properties that support script binding for the target control.
2. Open the script editor and write your business logic code in it.
3. At the end of the script, assign the calculated value to the specific target property.
4. Save the script.

**Tip**: The script binding function is powerful, and it is recommended that users have basic programming knowledge. For simple associations, prioritize using variable binding and property binding to improve performance and maintainability.
