Single-server deployment is the most basic deployment method for DipuOne. The configuration of single-server deployment is very simple, and other more complex deployment methods are also based on single-server deployment.

Single-server deployment refers to deploying DipuOne on one server, where this DipuOne node can connect to multiple PLCs, OPC UA servers, and databases. DipuOne in single-server deployment can use the built-in SQLite database to store historical data, or connect to other database servers and store historical data in other databases. At the same time, this server allows any number of clients to perform remote access.
