### **Recommended Hardware Configuration**

CPU: x86 64-bit architecture, 4 cores or more

Memory: 16GB

Hard Disk: SSD or higher performance hard disk, 10G or more available hard disk space

**The server hardware configuration requirements are directly related to the number of devices the customer project needs to connect, communication protocols, collection points, collection frequency, historical storage requirements, alarm quantity, script quantity and complexity, etc.**



### **Minimum Hardware Configuration Requirements**

CPU: x86 64-bit architecture, 4 cores

Memory: 4GB

Hard Disk: SSD or higher performance hard disk, 10G or more available hard disk space
