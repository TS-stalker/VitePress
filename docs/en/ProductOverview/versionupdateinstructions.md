DipuOne is continuously developing and updating. Each version introduces new features and bug fixes. Here you can quickly preview the new features and fixes for the corresponding versions.

### New Features

### 1.0.0

- **Permissions**: Support for single sign-on; permissions can be set for projects and screens.

- **Table Controls**: Display data in table format. You can customize the table's display content, style, and interaction effects.

- **Two-way Binding**: Variables, indirect variables, and properties support two-way binding. For example, when a control is bound to a variable, the value on the control will change synchronously when the variable changes; when the control's value is modified, the variable's value will also be modified synchronously.

- **Property Binding**: Added "Dynamic Variable" binding and "Cell Replacement" binding.

- **Symbols**: Symbols can be used to create model views of complex devices or systems, supporting combinations of multiple components and sub-symbols, making it easy for users to observe the overall system operation. DipuOne supports user-defined symbols, improving user operation efficiency.

- **Property Binding**: Added "Dynamic Variable" binding and "Cell Replacement" binding.
