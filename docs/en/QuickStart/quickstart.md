We outline some simple steps to guide you in configuring a project. You can run a project in a short time.

### 1. Create Project

In the project list, click the "Add New" button to create a project.

![Image Description](../../images/QuickStart/1.png)

On the add new page, fill in the required "Project Name" field to quickly create a project. Project image, responsible person, responsible person's phone, and description are optional fields.

![Image Description](../../images/QuickStart/2.png)

### 2. Open Editor

On the project list page, click the "Design" button of the project.

![Image Description](../../images/QuickStart/3.png)

Open the configuration editor, displaying the following interface.

![Image Description](../../images/QuickStart/4.png)

### 3. Create New Screen

Click "New Screen" to quickly create a screen.

![Image Description](../../images/QuickStart/5.png)

In the tool window on the right side of the designer, add "Text Input Box" and "Custom Curve" controls to the screen.

![Image Description](../../images/QuickStart/6.png)

Select the text input box, enter the text "Test Demo" in the property panel on the right. Note that all changes to the screen need to be saved to take effect at runtime.

![Image Description](../../images/QuickStart/7.png)

### 4. Preview and Run

Click the preview button in the screen menu bar to view the preview effect. You can also click the run button of the project in the project list to view the running page.

![Image Description](../../images/QuickStart/8.png)
