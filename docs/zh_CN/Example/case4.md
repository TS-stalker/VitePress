## 一、概述

定时导出报表是实现数据自动化归档和分发的关键功能。本案例将完整演示从**配置数据归档**、**创建数据集与报表**到**设置定时任务**的全流程。

## 二、操作步骤

### 步骤1：配置数据归档（确定要记录哪些数据）

报表的数据来源于历史记录，因此首先需要明确哪些变量值需要被系统记录。

1. 进入 **“连接管理”**。
2. 找到并选中需要导出数据的**变量**，切换到 **“归档视图”**。
3. 点击配置，设置归档策略：

   1. **记录类型**：选择记录方式（如：按数据变化记录、定时记录）。
   2. **起始时间**：设置从何时开始记录此变量的历史值。
4. 保存配置。此后，该变量的值变化将按策略被记录到历史数据库中。

![图片描述](../../images/Example/case4/1.gif)

### 步骤2：创建数据集（定义报表的数据来源）

报表需要一个明确的数据范围。

1. 进入 **“数据集”** 管理模块。
2. 点击 **“新增”**，创建一个新数据集。
3. 在数据集中，**添加步骤1中已配置归档的变量**作为数据源。您可以添加多个变量，并对它们进行筛选、排序等设置。

![图片描述](../../images/Example/case4/2.gif)

### 步骤3：设计报表（定义数据的呈现形式）

1. 进入 **“报表设计”** 模块。
2. 点击 **“新增报表”**，创建一个新报表。
3. 在报表的 **“数据源”** 设置中，**选择步骤2创建的数据集**。
4. 设计报表布局，如添加表格、图表，并绑定数据集中的字段。保存后，您即可在预览中看到基于历史数据的报表内容。

![图片描述](../../images/Example/case4/3.gif)

### 步骤4：创建定时导出任务（实现自动化）

1. 进入 **“任务管理”** 模块。
2. 点击 **“新增”**，创建一个新任务。
3. 配置任务：

   1. **任务名称**：为任务命名（如“每日能耗日报”）。
   2. **报表选择**：**选择步骤3中创建的报表**。
   3. **调度类型**：选择 **“定时”**。
   4. **调度配置**：设置具体的执行时间（例如：每天凌晨2:00）。
   5. **数据时间范围**：设置每次执行时，报表应包含哪段时间的数据（例如：导出“昨天”的数据）。
4. 启用并保存任务。

![图片描述](../../images/Example/case4/4.gif)

## 三、流程总结

整个自动化流程遵循清晰的数据流：**配置变量归档（记录数据）** → **创建数据集（组织数据）** → **设计报表（展示数据）** → **设置定时任务（自动执行）**。

任务将按照您设定的时间自动运行：系统会从历史库中取出指定时间范围的变量数据，通过数据集组织，填入报表模板，最终生成文件（如Excel）并保存或发送，实现无人值守的报表自动化。
