## 一、概述

项目属性是项目的全局配置中心，用于定义和修改项目的基本设定、初始状态、交互体验以及国际化等核心运行参数，确保项目能够按照预期启动和运行。

## 二、属性配置详解

| 配置项   | 描述                                                                                                       |
| -------- | ---------------------------------------------------------------------------------------------------------- |
| 项目名称 | 显示当前所属项目的名称。                                                                                   |
| 启动画面 | 设置项目运行时的初始画面。默认为创建的第一个画面。设置后，在项目列表中点击“运行”按钮时，将自动打开此画面。 |
| 报警     | 设置报警的等级、名称、字体颜色、列表背景色等，用于定义报警信息的视觉呈现。                                 |
| 语音     | 配置报警时的语音提示功能，包括：启用/禁用、音高、音量、语速，并可指定播报的报警文本。                      |
| 语言     | 为适应不同国家用户，配置项目中启用的语言。默认开启中文和英文。配置后，用户可在运行时切换界面语言。         |

## 三、配置流程

1. 在项目编辑器界面，找到并打开 **“项目属性”** 设置面板。
2. 根据需求，在 **基本信息、启动设置、报警配置、语音提示、国际化**等分类下进行配置。
3. 保存设置，配置将应用于整个项目的运行环境。

**注意**：部分配置（如启动画面）需在项目**发布或重新运行**后生效。
