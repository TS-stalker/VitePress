## 一、概述

变量绑定是构建动态应用的核心机制，通过将画面控件的属性与数据变量建立关联，实现数据在界面中的实时映射与交互。当绑定的变量值发生变化时，界面将自动同步更新，反之亦然，形成双向数据流。

## 二、变量库分类

| 变量分类 | 描述和包含内容                                                                                               |
| -------- | ------------------------------------------------------------------------------------------------------------ |
| 所有变量 | 展示系统中定义的全部变量，包含每个变量的名称、数据类型、详细描述，提供最全面的变量视图。                     |
| 系统变量 | 展示由系统预定义和维护的变量列表，目前展示的是系统时间                                                       |
| 连接状态 | 专门展示连接管理中的连接，包含其名称、类型和描述。                                                           |
| 系统状态 | 展示的是服务器状态信息                                                                                       |
| 离散变量 | 展示所有非结构化的基本变量列表，该类变量为自定义的变量，如整数、浮点数、布尔值、字符串等单一数据类型的变量。 |
| 结构变量 | 展示结构化的复合变量列表，该类变量为设备点表所对应的设备变量，可用于组织和管理一组相关的数据。               |
