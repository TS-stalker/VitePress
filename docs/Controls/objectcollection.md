## 一、功能概述

大纲视图是界面的**结构化导航器和内容清单**。当您在**项目**上选中某个具体项目（如画面、弹窗）时，大纲将以清晰的树状列表形式，**完整展示该项目中包含的所有构成元素**，包括所有**控件、图符**以及来自**图库的图片**，帮助您快速了解画面结构和定位特定元素。

## 二、视图说明

如图1-1所示，大纲视图通常呈现以下关键信息：

### 1. **树状层级结构**

- **根节点**：画面里面所有的控件、图符、图片
- **子节点**：组合控件里面的元素 ，图符里面的子元素等

### 2. **元素列表与状态**

| 元素类型 | 图标/标识                          | 状态显示                         |
| -------- | ---------------------------------- | -------------------------------- |
| 基础控件 | 各类控件特有图标（如按钮、输入框） | 名称、锁定/隐藏状态              |
| 图符实例 | 图符专用图标                       | 图符名称、展开可查看其内部子控件 |
| 图片资源 | 缩略图或图片图标                   | 图片名称、来源图库               |

**注意**：每个元素项旁通常会有**状态标识**，如：

- **锁形图标**：表示该元素已被**锁定**，无法在画布上直接编辑。
- **眼睛图标**（开启/关闭）：表示该元素的**可见性**，关闭时元素在运行时隐藏。

### 3. **交互操作**

- **快速定位**：在大纲列表中**单击**任一元素，画布上对应的元素将同时被**选中**。
- **右键菜单**：在大纲列表中**右键**单击任一元素，可进行**删除**操作。

## 三、应用价值

通过大纲视图，您可以：

- **快速盘点**：一目了然地掌握画面中所有元素的**种类和数量**。
- **精准定位**：在复杂画面中，绕过视觉重叠，**直接从列表中找到并选中**目标元素。
- **结构管理**：方便地调整元素层级、批量修改属性（如同时隐藏多个元素）。
- **辅助编辑**：当元素在画布上被其他元素遮挡或尺寸太小时，通过大纲操作更为便捷。

总之，大纲视图是管理和编辑复杂画面的强大辅助工具，它将视觉化的布局转化为结构化的数据，极大提升了设计效率与准确性。
